\# 物料进销存看板



\## 用途



展示库存、缺货、库龄、出入库、库存价值及省份出库分析。



\## 更新方式



运行仓库根目录中的“一键更新物料看板.bat”。



\## GitHub Desktop 提交范围



更新该看板时，只勾选：



\- material-dashboard/

\- build\_material\_dashboard.py

\- 一键更新物料看板.bat

\- 一键发布物料看板到GitHub.bat



\## 注意事项



\- 不要提交 \_\_pycache\_\_ 目录和 .pyc 文件。

\- 不要同时勾选其他看板的文件。

\- 出入库数据位于 assets/data 目录。
